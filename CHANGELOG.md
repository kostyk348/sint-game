# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/), версии — [SemVer](https://semver.org/).

## [Unreleased]

### Added
- **Долгая память между сессиями**: `play --save/--load` сохраняют состояние ядра (включая
  `rng`) ВМЕСТЕ с фактами и историей; команда `sintgame memory` показывает, что игра помнит.
  Совместимо со старым форматом. `docs/MEMORY.md`.
- Тесты +3 (всего 51).

### Added
- **Локальный веб-чат** (`chat.py`, `serve.py`, `sintgame serve`): персонажный чат в браузере
  на stdlib HTTP. Персонажи — NPC миров (`voice`/`desc`) и/или JSON-карточки; память диалога;
  ответы в роли. Локально, без облака и зависимостей.
- Тесты +3 (всего 48).

### Added
- **Открытый песочный режим** (`sandbox.py`, `sintgame sandbox`): миры без обязательных
  концовок (`compile --sandbox`), непрерывные прогоны 500+ шагов, опциональный **директор**,
  добавляющий события в рантайме под воротами.
- **Валидатор стабильности**: `validate` ловит петли триггеров (каскад упирается в guard) —
  иначе компилятор мог собрать мир, ломающийся на первом ходу.
- Примеры `examples/campaign` (длинная кампания, avg 80+ ходов) и `examples/sandbox`
  (открытый мир без концовок).
- Тесты +3 (всего 45).

### Added
- **Редактор** (`editor.py`, `sintgame editor`): самодостаточный HTML — обзор, свидетели
  достижимости, таблица действий, SVG-граф зависимостей, JSON-экспорт.
- **Баланс** (`balance`): + средняя длина партии.
- **Тюнинг** (`tune.py`, `sintgame tune`): авто-подбор числовых констант под баланс концовок
  (hill-climb по симуляции); честно сообщает, когда дисбаланс структурный, а не числовой.
- **Прогон** (`run.py`, `sintgame run --turns N`): многоэпизодный соак с проверкой тупиков,
  нестабильных каскадов и авторских инвариантов.
- `docs/TOOLING.md`; тесты +9 (всего 42).

### Added
- **Долгая память голосов** (`memory.py`): факты игры + извлечение релевантных сцене (bounded
  prompt); поле `voice` у персонажей (компилятор и генератор контента их заполняют) — для
  консистентности прозы на длинной дистанции.
- **Компакция мира** (`compact.py`, `sintgame compact`): свернуть admitted-действия в мир (v2)
  и перевалидировать.
- **Диагностика достижимости** (`search.diagnose`, `sintgame diagnose`): какие атрибуты
  раздувают пространство состояний (цель для абстракции по порогам).
- **Документ стоимости** (`docs/COST.md`): измеренный расход токенов за ход + лёгкий агент
  (`tools/opencode/agent/sint-gen.md`) для снижения в ~6×.
- Тесты: +7 (всего 33), оффлайн.

### Added
- **Создание контента** (`content.py`, `sintgame add`): генерация NPC/предметов/локаций/
  квестов в существующий мир с верификацией (схема + мёртвые предпосылки + сохранение
  достижимости концовок); откат и переделка при провале.
- **Контекстная проза**: проза связна с последними событиями (`--context N`) и подхватывает
  описания упомянутых сущностей.
- **Интент**: семантическое сопоставление с существующими действиями (без дублей) и
  оффлайн-деградация (работает без LLM).
- Тесты: +12 (всего 26), оффлайн.

## [0.1.0] — 2026-09-30

### Added
- **Детерминированное ядро** (`kernel.py`): сущности, атрибуты, флаги, предметы, связи,
  триггеры, действия, концовки. `act()` отказывает при ложном `pre`; `state()`/`restore()`
  сохраняют состояние **включая `rng`** (детерминированный сейв/реплей).
- **Валидатор** (`schema.py`): схема, ссылочная целостность, инварианты, симуляция.
- **Компилятор мира** (`compile_world.py`): `lore.md → world.json` через LLM под валидатором.
- **Ворота** (`intent.py::gate`): структурные проверки + авторские инварианты
  (`constraints.vital`) через сухой прогон.
- **Свободный ввод**: текст → интент → известное действие или предложение нового (через ворота).
- **Проза** от LLM + кэш + режим `--variety`.
- **Дисциплина prompt-кэша** (`prompt.py`): стабильный префикс `world_bible`, `PrefixMonitor`.
- **Точный анализ достижимости** (`search.py`): BFS со свидетелями + поиск мёртвых предпосылок.
- **Команда `balance`**: распределение концовок по многим прогонам.
- CLI (`compile`/`validate`/`play`/`balance`), два примера-мира, 14 тестов, доки для разработчиков.
