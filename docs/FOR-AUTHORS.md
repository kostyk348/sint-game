# Для авторов: как сделать свою игру

Игра — это **лор** плюс **мир** (`world.json`). Кода писать не нужно.

## Шаг 1. Лор

Напиши файл вроде `examples/lighthouse/lore.md`: мир, персонажи, вводные, тон,
**обязательные концовки**. Компилятор любит конкретику:

```markdown
Мир: маяк на скале, зима, берег отрезан льдом.
Персонажи:
- Смотритель Марек. Виноват. Скрывает подделанный судовой журнал.
- Девочка Ия, 11 лет. Ищет отца. Не знает о вине Марека.
Тон: холод, вина, тишина, тёплое под всем этим.
Обязательные концовки:
1. правда — Марек признаётся Ие.
2. милосердие — игрок сжигает журнал ради девочки.
3. изгнание — Марек выгоняет игрока.
4. лёд — все замерзают, если тянуть.
```

## Шаг 2. Компиляция

```bash
sintgame compile my_lore.md -o my_world.json
```

Компилятор (LLM) заполнит схему, а валидатор проверит результат и заставит исправить
ошибки. На выходе — заголовок и симуляция достижимости:

```
COMPILED -> my_world.json: Соль
SIMULATION: {"endings_reached": {"exile": 159, "ice": 69, "truth": 46, "mercy": 26},
             "dead_ends": 0, "unstable": 0, "no_ending": 0, "trials": 300}
```

Если концовки не достижимы или есть тупики — компилятор вернётся к правкам.

## Шаг 3. Проверка

```bash
sintgame validate my_world.json
```

Валидатор скажет: `VALIDATOR: OK` + симуляция. Если ошибки — покажет их списком.

## Шаг 4. Играть

```bash
sintgame play my_world.json                 # интерактивно (меню)
sintgame play my_world.json --prose none    # без LLM-прозы (быстро, оффлайн)
sintgame play my_world.json --free "подойти к Ие и сесть рядом"
sintgame play my_world.json --variety       # живая проза (без кэша)
sintgame play my_world.json --state-out save.json
sintgame play my_world.json --state-in save.json
```

## Создание контента (расширение готового мира)

Когда мир уже есть, контент добавляется против **замороженного скелета** — с проверкой,
что игра не ломается:

```bash
sintgame add my_world.json --kind npc      -n 3 -o my_world.json
sintgame add my_world.json --kind item     -n 5 -o my_world.json
sintgame add my_world.json --kind location -n 2 -o my_world.json
sintgame add my_world.json --kind quest           -o my_world.json
```

Каждое дополнение проходит **верификацию**:

1. схема валидна;
2. нет мёртвых предпосылок (флаг требуется, но нигде не выставляется; предмет требуется,
   но ниоткуда не берётся);
3. все объявленные **концовки по-прежнему достижимы**.

Если проверка не прошла — дополнение откатывается, а LLM переделывает его с подсказкой
об ошибках (до `--rounds`). Это «шина контрактов»: контент генерят частями, но мир
остаётся связным.

Когда рантайм накопил много `admitted`-действий, сверните их в сам мир:

```bash
sintgame compact my_world.json        # свёртка .ext.json в v2 + перевалидация
sintgame diagnose my_world.json       # какие атрибуты раздувают пространство состояний
```

## Крутить механики

Всё — в `world.json`. Можно править руками:

- **Атрибуты**: `"attrs": {"hp": 18, "guilt": 60, "cold": 10}`.
- **Действия**: добавить/изменить `{id,label,pre,eff}`.
- **Триггеры**: `{pre, eff, once}` — реакции мира (смерть, провал, разоблачение).
- **Концовки**: эффект `["end","<id>"]` (обычно с `["say","..."]` перед ним).
- **Инварианты**:

  ```json
  "constraints": { "vital": ["marek", "iya"], "min_hp": 1 }
  ```

  `vital` — персонажи, которые не должны погибать от произвольных действий игрока.
  Ворота это исполняют (см. `GATE.md`).
- **Голос персонажа**: `"voice": "как говорит (тон, манера, длина реплик)"`. LLM держит
  манеру в прозе и помнит факты (долгая память) — см. `sintgame add`.

### Пример: добавить механику

Хочешь «холод убивает»? Добавь триггер:

```json
{ "once": true,
  "pre": [["ge", "player.cold", 100]],
  "eff": [["say", "Холод забирает сначала пальцы, потом мысли."], ["end", "ice"]] }
```

Хочешь прочность предмета — используй атрибуты: `["add","lighter.fuel",-1]` в действии,
и триггер «сломался» на `["le","lighter.fuel",0]`.

## Формат мира

Полная схема — в `docs/COMPILER.md` и в строке-подсказке `sintgame compile`. Кратко:

```json
{
  "schema": 1, "title": "…", "tone": "…", "seed": 42,
  "entities": { "id": {"type":"…","tags":[],"attrs":{},"desc":"…"} },
  "holds":    [["holder","item"]],
  "relations":[["from","to","type",0]],
  "flags":    {"name": 0},
  "actions":  [{"id":"…","label":"…","pre":[…],"eff":[…] }],
  "triggers": [{"pre":[…],"eff":[…],"once":true}],
  "constraints": {"vital":["…"],"min_hp":1}
}
```

## Советы

- **Меньше, но связнее.** 8–14 действий с зависимостями (журнал + зажигалка + вина) интереснее
  40 несвязанных.
- **Ресурсы с давлением.** `cold`, `fuel`, `guilt` — то, что растёт/падает и создаёт выбор.
- **`vital` обязателен**, если персонажи не должны умирать случайно.
- **Концовки формулируй явно** в лоре — компилятор их воспроизводит.
