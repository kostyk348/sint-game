# Ворота: почему «нет» — это фича

## Закон

> **LLM предлагает — ворота решают.**

Понимать свободный текст можно сколь угодно широко. Но **менять состояние** может только
то, что прошло ворота. Это граница между «живой игрой» и «сном, где ничто не значит ничего».

## Зачем

Если бы LLM мог менять правила в рантайме свободно, ты бы потерял:

- **воспроизводимость** (seed больше ничего не гарантирует),
- **тестируемость** (баги неотловимы),
- **баланс** (сегодня отравление 3 хода, завтра 5),
- **сейвы и откаты**.

Поэтому: LLM-предложение — это **данные**, а не действие. Данные проходят проверку и лишь
потом становятся частью мира.

## Два уровня ворот (`intent.gate`)

### 1. Структурные (всегда)

| Проверка | Пример отказа |
|---|---|
| Схема условий/эффектов | `["teleport","player","home"]` → unknown op |
| Ссылочная целостность | `["dmg","ghost",5]` → нет сущности `ghost` |
| Границы дельт | `["add","player.hp",999]` → \|delta\| > 40 |
| Запрет новых концовок | `["end","newend"]` → рантайм не создаёт концовки |
| Непустые эффекты | `"eff": []` |
| Уникальность id | id уже существует |
| Выполнимость `pre` | условие сейчас ложно |

### 2. Авторские инварианты

Автор объявляет в мире:

```json
"constraints": { "vital": ["marek", "iya"], "min_hp": 1 }
```

Ворота делают **сухой прогон** действия на копии мира и отклоняют, если персонаж из
`vital` погибает:

```
lethal via dmg        -> REJECT: инвариант нарушен: marek.hp=-22 < 1
lethal via dead-flag  -> REJECT: инвариант нарушен: marek помечен мёртвым
```

## Главный урок (и он стоил нам бага)

Структурные ворота сами по себе **пропустили** действие «зарезать Марека» — убийство
структурно легально. Структурная проверка ≠ дизайнерская. Второй уровень (`constraints`)
обязателен.

Аналогично: живой агент часто добавляет невыполнимые предусловия (`["has","player","яд"]`),
и ворота отклоняют предложение на шаге «pre ложен». Это нормально: мир говорит LLM «нет».

## Что тестируется

`tests/test_gate.py` — 8 случаев: 7 отказов + 1 законное действие. Всё оффлайн.

## Философия

Игра, которая принимает **любое** действие, — не игра. Отказ — часть дизайна: он удерживает
мир связным. Задача — не «пропустить всё», а «пропустить то, что мир выдержит».
