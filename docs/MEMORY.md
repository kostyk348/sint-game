# Долгая память (РПГ)

Что игра помнит между запусками и как это устроено.

## Три уровня памяти

| Уровень | Что это | Где живёт |
|---|---|---|
| **Состояние ядра** | флаги, атрибуты, предметы, связи, концовка + **`rng`** | сериализуется целиком |
| **Факты** | текстовые события ходов с привязкой к сущностям | накапливаются, ограниче­ны `max_facts` |
| **История** | последние действия (для связности прозы) | окно `--context` |

## Один файл сейва

`--save` / `--load` пишут и читают **одну сессию**:

```json
{ "version": 1, "world": "Соль", "turn": 3,
  "state": { "...": "полное состояние ядра, включая rng" },
  "memory": [ {"turn":1,"text":"...","entities":["iya"]}, ... ],
  "history": ["Поговорить с Ией", "..."] }
```

- состояние продолжается **побитово** (включая `rng`) — реплей не разъезжается;
- факты и история **переживают перезапуск** — новая сессия помнит вчерашнее;
- старый формат (сырой `state` без обёртки) тоже принимается.

## В промпт идёт только релевантное

Факты фильтруются по сущностям текущей сцены (`FactLog.relevant`): в прозу попадают
только те, что относятся к действующим лицам. Поэтому память может расти годами, а
промпт — нет. Голоса персонажей (`voice`) и описания (`desc`) — в стабильном префиксе
(prompt-cache не ломается).

## Команды

```bash
sintgame play world.json --save  session.json     # сохранить состояние + память
sintgame play world.json --load  session.json     # продолжить (новая сессия)
sintgame memory session.json                      # посмотреть, что игра помнит
```

## Пример (проверено)

```bash
# сессия 1 (новая игра)
sintgame play examples/lighthouse/world.json --script talk_iya,press_marek,search_cabin \
         --prose none --save /tmp/lh.json
# → долгая память сохранена: ход 3, фактов 3

sintgame memory /tmp/lh.json
# world: Соль | ход: 3 | фактов: 3
#   - Ия греет руки о печь. «Отец обещал вернуться до льда...»
#   - Ты спрашиваешь прямо, почему маяк молчал в ту ночь...
#   - Под койкой — ящик. Замок поддаётся ножу. Внутри — судовой журнал «Соли»...

# сессия 2 (новый процесс) — продолжаем с того же места
sintgame play examples/lighthouse/world.json --load /tmp/lh.json --script reveal_truth --prose llm
# → [долгая память: /tmp/lh.json — ход 3, фактов 3]
# → журнал уже найден, вина набрана → концовка truth
```

## Честное ограничение

Факты — это **текстовые события**, а не структурированное знание. Кто что знает о ком
(«Ия не знает о вине Марека») не моделируется отдельно — это задача автора и дизайна
мира (флаги, отношения). Память даёт связность прозы, а не «theory of mind».
