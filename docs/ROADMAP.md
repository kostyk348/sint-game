# Roadmap

Честная карта: что уже есть, чего нет, что делать дальше. Порядок — по ценности/риску.

## Есть (ядро)

- Детерминированное ядро (сущности/атрибуты/флаги/предметы/связи/триггеры/концовки).
- Компилятор `lore → world` (LLM) под валидатором.
- Валидатор (схема + инварианты + симуляция достижимости).
- Ворота (структурные + `constraints.vital`).
- Свободный текст → интент → действия (с воротами).
- Проза LLM + кэш + режим `--variety`.
- Сейв/лоад состояния с `rng`.
- Дисциплина prompt-кэша (стабильный префикс).
- 2 примера-мира, 10 тестов.

## Нет (до «полноценной игры»)

### Ближайшее (инженерное)

1. **Граф предусловий в валидаторе.** Сейчас достижимость — Монте-Карло (трудные концовки
   видны 1–2/300). Нужен BFS/символьный анализ графа условий → гарантия достижимости.
2. **Компакция мира.** Сейв = базовый мир + `admitted`-действия (`.ext.json`). При долгой
   игре мир дрейфует → нужен оффлайн-проход «свернуть дельты в v2 и перевалидировать».
3. **Variant-salt прозы** как явный механизм (сейчас `--variety` рубит кэш целиком;
   нужен аккуратный «детерминизм для реплея + разнообразие для игры»).
4. **Расширение словаря действий/эмоций** под free-text (сейчас «обнять» может стать
   «поговорить» — это место, где автор задаёт игру).

### Дальше (продуктовое)

5. **Консистентность голосов на 50+ ходов** — контекстная проза, которая помнит историю
   (а значит, меняется ключ кэша и нужна осторожность с prompt-cache).
6. **Редактор мира / инструмент автора** — UI для правки `world.json`, инвариантов, просмотра
   графа достижимости. Это и есть «инструменты» из позиционирования.
7. **Балансировка через симуляцию** — массовые прогоны, распределения, автоподбор чисел.
8. **Мультимир / кампании** — несколько миров, перенос состояния, общая шина контрактов.
9. **Низколатентный инлайн-вызов LLM** вместо `opencode run` (для тесной интеграции).

## Открытые вопросы (продуктовые)

- **Трек.** Это пивот или отдельный проект? Третий активный трек повышает риск, что один
  умрёт тихо. Решение владельца.
- **Граница «живости».** Детерминизм vs разнообразие — фундаментальное противоречие;
  снимается только двумя режимами (replay/live).
- **Что отгружаем первым.** Киоск-миры (сценарии) или редактор для авторов?

## Метрики, по которым судить

- Доля концовок, достижимость которых **доказана** (не «найдена случайно»).
- Стабильность префикса (prompt-cache hit rate).
- Консистентность голоса: доля реплик персонажа, не противоречащих характеру, на дистанции.
- Доля действий, предложенных LLM, которые **прошли ворота** (слишком низкая → ворота
  душат; слишком высокая → мир не защищён).
