# Инструменты автора: редактор · баланс · тюнинг · прогон

Четыре команды, которые замыкают цикл «сделать мир → проверить → настроить → погонять».

## Редактор — `sintgame editor`

```bash
sintgame editor world.json -o world.editor.html
```

Пишет **один самодостаточный HTML** (без сети, без зависимостей). Внутри:

- **Обзор** — сущности, действия, концовки;
- **Достижимость** — каждая концовка и её **свидетель** (последовательность действий);
- **Действия** — таблица `pre`/`eff`;
- **Граф** — SVG: *флаги/предметы → действия → продукты* (цветом: флаги, предметы, концовки);
- **JSON** — правка мира и кнопка «Скачать world.json».

Открывается двойным кликом. Правки — в JSON-вкладке, после — `sintgame validate`.

## Баланс — `sintgame balance`

```bash
sintgame balance world.json --trials 3000
```

Распределение концовок, средняя длина партии, доля «без концовки», тупики, нестабильность.
Если какая-то концовка > 70% — предупреждение о вероятном дисбалансе.

```
balance: 3000 trials | no_ending=0 dead_ends=0 unstable=0 avg_turns=7.2
             exile   1643   54.8%
               ice    651   21.7%
```

## Тюнинг — `sintgame tune`

```bash
sintgame tune world.json -o tuned.json --trials 300 --iters 80
```

Собирает **числовые константы** мира (значения эффектов и пороги условий) и hill-climb'ом
двигает их, чтобы распределение концовок стало ровнее (все достижимы, меньше тупиков).
Результат детерминирован по `--seed`.

> **Честное ограничение:** тюнер правит **числа**. Если дисбаланс структурный (одна
> концовка тривиально достижима по цепочке событий), числа его почти не исправят — надо
> менять структуру (условия, ветвления). Тюнер это честно показывает: `improved: false`.

## Прогон — `sintgame run`

```bash
sintgame run world.json --turns 60 --policy explore
```

**Многоэпизодный соак**: играет N ходов (если мир заканчивается — новый эпизод с новым seed),
на каждом ходу проверяя инварианты:

- нет тупиков;
- нет нестабильных каскадов триггеров;
- персонажи из `constraints.vital` не падают ниже `min_hp`.

```
soak: 60 turns across 7 episodes (policy=explore, seed=0)
  endings: {'truth': 5, 'mercy': 1}
  violations: 0
  unused actions: []
```

Политики: `random`, `explore` (сначала неиспользованные), `greedy` (предпочитает действия,
меняющие состояние), `linger` (не выбирает действия, создающие концовку). Так проверяется,
что мир **устойчив на длинной дистанции** и что все действия достижимы.

## Песочница и долгие кампании — `sintgame sandbox`

```bash
sintgame sandbox world.json --turns 500 --policy linger
sintgame sandbox world.json --turns 200 --every 20 --director llm   # мир растёт в рантайме
sintgame compile my_lore.md -o open.json --sandbox                  # мир без концовок
```

**Открытый режим** (в духе Pax Historia):

- мир может **не иметь концовок** — это не ошибка, а сэндбокс (`reachability: OPEN WORLD`);
- **непрерывный прогон** 500+ ходов в одном состоянии (без перезапусков);
- **директор**: каждые K ходов LLM предлагает новое событие-действие. Каждое проходит
  ворота (схема + мёртвые предпосылки; концовки запрещены) и вплавляется в живой мир.
  Так контент не заканчивается, а структура держит связность.

```
sandbox: 500 turns continuous (policy=linger, seed=0)
  ended: нет (открытый финал)
  distinct actions used: 27 / 37
  dead-ends: 0
  director: 3 calls, +3 actions
  violations: 0
```

> **Про стабильность.** Валидатор ловит **петли триггеров** (каскад упирается в guard).
> Это дым-тест правил: если петля срабатывает на первых ходах — её поймает и человек.
> Если она достижима только экзотической последовательностью — это всё равно латентный
> баг правила (состояние достижимо), но приоритет ниже.
